# Честный знак — помощник для бизнеса

## Идея

Создать веб-сервис, который упрощает работу малого бизнеса с системой маркировки «Честный знак».

Сервис должен помогать предпринимателю получать коды маркировки и выполнять связанные с этим операции через более понятный и удобный интерфейс.

## Для кого

Для малого бизнеса и компаний, которым необходимо работать с маркировкой товаров.

## Какую проблему решаем

Работа с маркировкой может требовать много рутинных действий и разбираться в большом количестве процессов.

Наш сервис должен упростить эту работу:

* уменьшить количество ручных действий;
* сделать процесс получения кодов понятнее;
* показывать понятные статусы операций;
* помогать пользователю разбираться с ошибками.

## Основной сценарий

Пользователь заходит в сервис → выбирает нужную операцию → указывает данные → сервис обрабатывает запрос → пользователь получает понятный результат и статус операции.


## Основной сценарий: получение кодов

1. пользователь заходит на свой аккаунт
2. заходит во вкладку запрос кодов
3. запрашивает через кнопку получение кодов
4. сервер получает запрос 
5. отправляет данные на честный знак
6. пользователю приходит оповещение при успешной отправке что запрос отправлен
7. сервер получает коды
8. отправляет коды пользователю
9. пользователь получает коды 

## MVP

Первая версия сервиса должна позволять:

* зарегистрироваться и войти в систему;
* создать организацию;
* добавить необходимые данные о товаре;
* создать запрос на получение кодов маркировки;
* увидеть статус запроса;
* посмотреть историю операций.

## Что не входит в MVP

На первом этапе не реализуются:

* мобильное приложение;
* сложные автоматизации;
* большое количество типов операций;
* интеграции со всеми возможными сервисами бизнеса;
* расширенные AI-функции.

## Будущий функционал

В дальнейшем можно добавить:

* проверку файлов;
* автоматическую обработку типовых операций;
* уведомления;
* расширенного AI-помощника;
* дополнительные операции с маркировкой;
* интеграции с учётными системами и другими сервисами;
* мобильное приложение.
